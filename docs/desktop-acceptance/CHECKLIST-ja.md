# Windows 10/11 実機受入チェックリスト（実施停止中）

**現在は開始できません。** TaskPilot 0.4.0.2の一般版・独立モードの公開停止を維持し、承認済みの実機検証用EXE・ZIPはありません。新しい受入専用入口と検査も開始条件の不足により`BLOCKED`です。この文書は将来の承認済み受入ビルドに対する試験計画です。現在のEXEへ引数を付けたり、設定・スクリプト・環境変数を変更して停止を回避しません。

[開始条件](READINESS-ja.md)を満たした検証ビルドが指定されるまで、下記31件はすべて**未実施（開始停止）**です。[初心者向け手順](README-ja.md)と[結果記録用紙](RESULT-TEMPLATE-ja.md)を併用してください。Windows 10とWindows 11は別々に記録します。

## 試験全体のルール

- 入力は、この試験のために作った架空の「UAT-」データだけです。既存のTaskPilotデータを探す、開く、コピーする、移行する、ハッシュを採る操作をしません。
- OSごとに指定された新規のテスト環境IDを使い、そのOS内の再起動では**同じID**を使います。保存先は承認済みビルドが表示した専用領域だけです。自分で通常版の保存先や一時フォルダーを指定しません。
- 専用起動前検査が必要です。`READY_FOR_DESKTOP_ACCEPTANCE` は専用入口が要求する判定名ですが、**現在この開始許可を返せる構成はありません**。対象WindowsでGUI前に行う安全性検査の実装も不足しています。`BLOCKED`や旧版の別のREADY判定を、この試験の起動許可として使いません。
- インターネット由来のブロック、署名・ハッシュの不一致、SmartScreen等の停止は、そのまま「停止」とします。保護の解除、管理者起動、実行ポリシーの変更、DLLの差し替えをしません。
- 表示に `[ACCEPTANCE ONLY]` と環境IDがない、旧データの移行画面が出る、専用領域以外の保存先が表示される場合は、その場で停止します。`[TEST MODE]`だけの既存入口では代用しません。移行や復元を承諾しません。
- 合格は、期待値と保存結果を確認して証跡を残せた場合だけです。到達できなかった機能は「未実施」または「停止」です。「対象外」は理由が必要で、ブロックされた機能を対象外や合格へ振り替えません。

## 入力する架空データ

試験日をD、その月をMとします。タスクIDはアプリが発行した値を控え、下の呼称と結び付けます。IDの数値を決め打ちしません。 日付や対象月をまたいだ場合は、そのケースの条件を記録して停止し、新しい基準で再開する方法を担当者に確認します。OSの時計は変更しません。

| 呼称 | 入力例 | 用途 |
| --- | --- | --- |
| T1 | タスク名 `UAT-受入A_日本語 ' " ; SELECT`、優先度「高」、状態「対応中」、開始日・実施予定日・期限D、予定5.01h、備考 `=1+1` | 編集・子・日別記録・Excel文字列 |
| T2 | `UAT-受入B_別タスク`、優先度「低」、状態「未着手」、予定0h、開始日・予定日未指定 | 親子の分離・未指定値・復元 |
| T3 | `UAT-受入C_完了実績`、予定2.00h、開始日・予定日・期限D | 完了申告1.25h |
| TD | `UAT-受入D_削除専用`、予定0h、子1件と前月の日付の0.25h記録 | 削除の取消・承諾 |

予定5.01hは数値欄へ直接入力します。日別記録は0.75hと0.26hの2件にします。GUIで入力できない最小値や改行を無理に入力したことにはせず、そのような内部データ検証は開発者の合成試験に分けます。

## 開発者が先に確認する隔離試験

実ユーザーの既存TaskPilotフォルダーを列挙・読み取り・ハッシュ比較する試験は行いません。開発者だけが新規の合成プロファイルへ通常版のダミーDB・CSV/JSON・設定・バックアップ・ロックを作り、受入候補の操作前後でダミーのハッシュと構成を比較します。リンク・ジャンクション・hardlink・中断・容量不足などは、その合成環境内の専用試験に分けます。

この開発者試験・承認されたビルドの識別・起動前検査・標準権限・安全な取得経路が揃わない状態で、初心者向けGUI受入を開始しません。

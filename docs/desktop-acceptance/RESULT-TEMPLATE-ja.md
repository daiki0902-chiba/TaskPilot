# Windows 10/11 実機受入 結果記録用紙

**これは未記入の用紙です。合格証明ではありません。** 一般版・独立テストモードの公開停止を維持しています。受入専用入口と検査の追加後も、承認済み実機検証キットと開始条件が揃っていないため開始判定は「停止」です。アプリは起動しません。

[開始条件](READINESS-ja.md)、[手順](README-ja.md)、[31件のチェックリスト](CHECKLIST-ja.md)と組み合わせます。Windows 10とWindows 11は下の別欄へ記録し、必要ならこのファイルをOSごとに複製します。同じPCの結果やServer CIを別OSの合格へ転記しません。

## 記録のルール

- ケース判定は「未実施」「合格」「不合格」「停止」「対象外」の5種類です。対象外には理由が必要です。
- 未確認は未実施のままにします。ブロックされた起動やDLLを対象外にしません。
- 初期値「開始条件未達：承認済み検証ビルド待ち」を、実際の観測値がないまま合格へ書き換えません。
- 実業務データを探す・コピーする・ハッシュを採ることはしません。試験で比較する通常領域は、開発者が作った合成ダミーだけです。
- 証跡は許可されたエラーコード・ケースID・ビルドIDに限定します。個人名・ユーザー名を含むパス・業務内容・例外全文・背景の業務画面は収集しません。DB・CSV・Excel・バックアップを自動添付しません。
- 現在停止しているログ採取ツールは使いません。承認された限定診断が未提供なら、下のエラー欄へコード・時刻・操作だけを手動で記録します。

# TaskPilot ご利用ガイド

TaskPilot は、タスク、予定工数、日別の作業記録、完了実績を管理する Windows 向けアプリです。この配布版は SQLite に保存します。旧版の CSV・JSON を編集しても、この版の保存済みデータは更新されません。

## 起動する

1. 配布 ZIP を、書き込み可能な通常のローカルフォルダーへすべて展開してください。ZIP 内から直接実行しないでください。
2. 展開したフォルダーの `TaskPilot.exe` を開いてください。
3. 初回は、次の「旧版から引き継ぐ」の案内が表示された場合だけ、内容を確認して進めてください。

対象は Windows 10 / 11 の 64 ビット環境、Windows PowerShell 5.1、.NET Framework 4.6 以上です。.NET Framework 4.8 を推奨します。SQLite、Excel 出力用モジュールは同梱します。購入者による PowerShell モジュールの追加インストールや Python の導入は不要です。Excel ファイルの作成には Excel 本体は不要ですが、ファイルを開くには `.xlsx` に対応したアプリが必要です。

`TaskPilot.exe` と、同梱の `Adapters`、`Modules`、`Codec` などのフォルダーは一緒に保管してください。EXE だけの移動や、DLL・モジュールの削除は起動・保存・Excel 出力の失敗につながります。`ThirdPartyNotices` と `ThirdPartySources` は、使用するソフトウェアのライセンスと対応ソースを収録しています。

この文書を整備した環境では、Windows 10 / 11 上の EXE、画面操作、通知、Excel 出力は未検証です。販売者は同梱するビルドの Windows 受入試験結果を確認してから配布してください。

## 旧版から引き継ぐ

旧版を終了してから、この版を起動してください。初回に `%LOCALAPPDATA%\TaskPilot` がある場合は、旧データを検査し、件数、警告数、検査結果ファイルの場所を表示します。警告があれば検査結果を確認してください。

承諾すると、旧データの完全バックアップを `%LOCALAPPDATA%\TaskPilot4LegacyBackups\LegacyBackup_（識別子）` に作成して、新しい SQLite データベースへコピーします。元のフォルダーは残ります。完了画面に表示されるバックアップと結果ファイルの場所を控え、引き継いだタスク・予定・実績を確認してください。以後はこの版で作業してください。旧版と新しい版を交互に使っても、変更は相互に同期されません。

中止した場合や検査エラーがある場合は、元データを変更せず起動を中止します。エラーを隠すために空のデータを作ることはありません。検査結果とエラーの記録は `%LOCALAPPDATA%\TaskPilot4Logs` に残ります。中止後は再起動して引き継ぎをやり直せます。エラーの場合も原因を解消して再試行でき、診断記録や作成済みの完全バックアップを削除する必要はありません。元データや検査結果を保管し、解決できない場合は表示された内容を販売者へ伝えてください。

## 日常の操作

- 「追加」でタスク名、優先度、期限、状態、備考、実施予定日、作業開始日、予定所要時間を登録します。行を選んで「タスク操作」から編集、完了、削除を行います。検索はタスク名と備考を対象にします。
- 「サブタスク管理」で選択したタスクの子項目を管理します。「作業実績（日別）」では、作業した日と時間を記録します。
- 完了したタスクの実績は、タスクを選んで「設定・管理 → 完了実績入力」から入力します。日別の作業記録と完了時の実績時間は別の指標です。合算すると二重計上になる場合があります。
- 「定期タスク管理」で繰り返しルールを管理します。「祝日・休業日管理」「稼働カレンダー設定」で営業日や稼働時間を設定します。
- 「月間稼働状況」で予定と実績を確認できます。「月次確定データ管理」では月次の確定結果と履歴を扱います。
- 「設定」で期限通知と毎日の通知時刻を設定します。毎日の通知はアプリの起動中だけ動作します。「通知」から手動確認と通知履歴を開けます。

変更が競合したというエラーが表示された場合は、編集内容を控え、画面を更新して最新の内容を確認してから操作し直してください。同じ Windows ユーザーの保存先を複数人・複数端末で共有する運用には対応していません。

## Excel を確認する

「ファイル表示」から、タスク一覧、完了タスク、ダッシュボードを開きます。出力先は `%LOCALAPPDATA%\TaskPilot4\Export` です。

Excel の更新に失敗した場合でも、タスクの保存が完了している場合があります。表示されたメッセージを確認し、出力済みの Excel を閉じてから「ファイル表示 → Excelを再出力」を実行してください。出力ファイルを編集しても、TaskPilot の保存データには反映されません。

## 保存先とバックアップ

Windows のエクスプローラーのアドレス欄に `%LOCALAPPDATA%\TaskPilot4` と入力すると、新しい版のデータ保存フォルダーを開けます。診断記録と旧データの完全バックアップは、その隣の別フォルダーに保管します。

| 内容 | 保存先 |
| --- | --- |
| 初回作成するデータベース | `%LOCALAPPDATA%\TaskPilot4\TaskPilot.db` |
| 使用中データベースの指定 | `%LOCALAPPDATA%\TaskPilot4\active-store.json` |
| SQLite バックアップ | `%LOCALAPPDATA%\TaskPilot4\Backup` |
| Excel 出力 | `%LOCALAPPDATA%\TaskPilot4\Export` |
| 操作・エラー・移行の記録 | `%LOCALAPPDATA%\TaskPilot4Logs` |
| 旧データの完全バックアップ | `%LOCALAPPDATA%\TaskPilot4LegacyBackups\LegacyBackup_（識別子）` |
| 引き継ぎ前の旧データ | `%LOCALAPPDATA%\TaskPilot` |

タスクの追加・編集・削除などの前に、整合性を検査した SQLite バックアップを作成します。バックアップは変更前の状態です。すべての操作の直後に最新状態がバックアップされるわけではありません。

別の場所にも保管する場合は TaskPilot と旧版を終了してから、`%LOCALAPPDATA%` 内の `TaskPilot4`、`TaskPilot4Logs`、`TaskPilot4LegacyBackups` の各フォルダーを、日付付きの別フォルダーへ丸ごとコピーしてください。存在するものをすべて保管し、旧データの `TaskPilot` フォルダーも残っていれば合わせて保管します。使用中 DB の指定、復元前の DB、診断記録、旧データの完全バックアップを含められます。アプリ実行中の `.db` だけをコピーする運用は避けてください。

`active-store.json` やデータベースは手作業で編集・削除しないでください。復元後は `TaskPilot_restored_（識別子）.db` という新しい名前の DB が使用されます。ファイル名だけから使用中 DB を判断せず、保存フォルダー全体を保管してください。

## バックアップから復元する

1. 「設定・管理 → バックアップ復元」を開きます。
2. 復元したい TaskPilot の SQLite バックアップ（`.db`）を選択します。
3. 確認画面で内容を確認して承諾します。現在の状態のバックアップを作成し、選んだバックアップを検査したうえで、新しい DB に復元します。
4. アプリが終了したら `TaskPilot.exe` を再起動し、内容を確認してください。

現在の DB は上書き・削除せず残します。復元は保存された業務データを対象とし、以前の Excel 出力やログを戻す操作ではありません。復元後、必要に応じて Excel を再出力してください。整合性や形式に問題があるバックアップは受け付けません。

## 更新・困ったとき

更新前にアプリを終了し、前述の保存先と記録・旧データの各フォルダーをバックアップしてください。新しい配布物は別のフォルダーへすべて展開して起動します。アプリの展開先とユーザーデータの保存先は別なので、展開先を変えても同じ Windows ユーザーのデータを使用します。旧版・旧配布物は、動作を確認するまで保管してください。

起動・保存・復元に失敗した場合は、エラーメッセージと発生した操作を控えてください。`%LOCALAPPDATA%\TaskPilot4Logs` の記録、使用したバージョン、Windows のバージョンを販売者へ伝えると調査に役立ちます。ログにはタスクなどの内容が含まれる場合があるため、送付前に確認してください。データが見えなくても、初期化や手作業によるファイル削除はせず、データ・記録・旧バックアップの各フォルダーをそのまま保管してください。

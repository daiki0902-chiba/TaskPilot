## 成果物の場所

8種類の成果物の対応表は[README](../README.md#成果物)にある。テスト結果の環境・対象を確認し、合格数だけでWindowsでの動作確認済みと判断しない。

GitHub Actionsの[Windows自動検証](../.github/workflows/windows-verify.yml)は、Windows Server 2022・Windows PowerShell 5.1・同梱native SQLiteを対象に、旧保存処理の回帰試験、8グループの自動試験、未署名の開発候補EXE生成を行う。Windows 10/11の実機受入、対話的なWinForms、通知、購入者のダウンロード経路を代行しない。実行結果と未実施項目は[販売判定](06-release-status.md)に記録する。

mainへ直接反映せず、専用開発ブランチと[ドラフトPR #1](https://github.com/daiki0902-chiba/TaskPilot/pull/1)でレビュー可能にしている。販売リリース・mainへのマージ・本番ユーザーデータへの操作は行っていない。
